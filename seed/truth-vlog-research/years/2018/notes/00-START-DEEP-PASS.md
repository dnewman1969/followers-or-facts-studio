2. Topics / lies in plain English
3. Link `claim_ids`, `person_ids`, `org_ids` (create new entity rows if missing)
4. Mark `deep_pass=yes` when that episode row is solid
5. Add sources to `research/sources/sources.csv` when you find real docs
